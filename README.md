# KeepGoing 単語帳

英熟語の単語帳アプリ。写真のデザインをそのまま再現したカード表示と、
Spotify のように聞き流せるリスニングモードが入っています。

ビルド不要。`index.html` をブラウザで開くだけで動きます。

## 使い方

### 単語帳
- 1 枚のカードに「番号・発音記号・見出し語・日本語訳・例文 2 本（英日）」。
  2 語目以降は同じカードが下に続きます。
- 上の検索欄で、単語・意味・発音記号・例文を横断して絞り込めます。
- 単語の横に再生ボタンはありません（発音記号のみ）。音声はリスニングモードに集約しています。

### リスニング
「リスニング」タブへ。**聞く範囲を自由に決められます。**

- **範囲で選ぶ** — 「開始 1 〜 終了 30」を指定。`1-10` `11-20` `21-30` `全部` のワンタップ切替つき。
- **個別に選ぶ** — チェックで「1, 5, 7, 20 だけ聞く」といった任意の組み合わせ。
  全選択／全解除／いまの範囲を選択に反映、各行の ▶ でその単語から再生。
- **読み上げのカスタマイズ** — 読む要素（見出し語・日本語訳・例文英・例文和訳）、
  繰り返し回数 1〜5、英語と日本語それぞれの速度、単語間の間、リピート（なし／全体ループ／1 語）、シャッフル。
- 設定と選択はブラウザに保存され、次に開いたときに復元されます。

#### バックグラウンド再生
- ロック画面・通知領域・イヤホンのボタンから再生／停止／前後の単語へ移動できます
  （Media Session API）。曲名の位置に見出し語、アーティストの位置に日本語訳が出ます。
- 他のタブや単語帳を見ている間は、画面下のミニプレイヤーで操作できます。
- **ホーム画面に追加して起動する**と、バックグラウンド再生が安定します。
- ⚠️ iOS / iPadOS の Safari は、OS の制限で画面ロック中に読み上げが止まることがあります。
  ロックを解除してリスニング画面に戻ると、再生位置から自動で復帰を試みます。
  Android / デスクトップの Chrome では画面を消しても継続します。

## 単語を追加する

`data/words.js` を編集するだけです。

```js
{
  id: 31,                                 // 連番
  term: "take after",
  ipa: "/ˈteɪk ˌæftər/",                  // 第一強勢 ˈ を入れる
  meaning: "〜に似ている",
  examples: [
    {
      en: "She really takes after her mother.",
      ja: "彼女は本当にお母さん似だ。",
      enMark: ["takes after"],            // en に実在する文字列（青くハイライト）
      jaMark: ["似"]                      // ja に実在する文字列
    }
  ]
}
```

`enMark` / `jaMark` は **例文に実際に含まれる文字列**にしてください（活用形が変わる場合はその形）。
追加したら `node tools/check.js` で検証できます（件数の期待値 30 は適宜変更）。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組みとカードの `<template>` |
| `css/tokens.css` | 配色トークン（写真の色はここに集約） |
| `css/styles.css` | 単語帳の見た目 |
| `css/listening.css` | リスニングの見た目 |
| `data/words.js` | 単語データ |
| `js/app.js` | 一覧描画・検索・タブ・`window.App` |
| `js/listening.js` | 再生エンジン・範囲選択・Media Session・`window.Listening` |
| `sw.js` / `manifest.webmanifest` | オフライン対応とホーム画面追加 |
| `tools/check.js` | Playwright による統合チェック |
| `docs/CONTRACT.md` | 実装契約（データ形式・API） |

## 開発

```bash
node tools/check.js
```

オフライン対応（Service Worker）とホーム画面追加は `http(s)` 配信時のみ有効です。
ローカルで試すときは次のように配信してください。

```bash
python3 -m http.server 8000
```
